# Support

`skillfixture-hub` is an early local-first CLI and ESM library. The supported
surface is the documented `skillfixture-hub` CLI commands and the typed helpers
exported from the package root, including validation and rendering helpers.

## Before Filing an Issue

Run:

```sh
npm run release:check
```

Include:

- The command you ran.
- A minimal redacted fixture file or generated summary.
- The expected validation result and the actual result.
- Your Node.js version.

Please redact private prompts, proprietary skill instructions, credentials, and live host paths before sharing examples publicly.
